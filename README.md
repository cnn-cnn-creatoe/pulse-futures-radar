## 本版能力

- 统一的「指标策略」研究库，包含 WaveTrend · 超买超卖交叉和自创「楠策略1超买超卖」；后者保留转折入场、相反转折平仓和同根先平后开的原始逻辑。
- 每项规则内置设置按钮，独立选择最低活跃度和最低可做度；两项同时满足才入选，0 表示不限。
- 已接入规则支持 1m、5m、15m、30m、1h、4h、日、周、月的收盘确认；北京时间显示，周期按 UTC 对齐。
- 图表买卖／固定观察期模拟退出箭头、信号定位、两点测量、形态、可做度和活跃度筛选。
- Telegram 每位用户、每条指标或策略独立设置周期、分数、形态和币种。
- 共享行情采集与历史补齐、限流退避、重启恢复、下载进度及缺口检查。

本次自创策略的回测报告见 [楠策略1回测报告](outputs/nan-strategy1-btc-3y/回测报告.md)。研究库合并历史见 [指标策略合并说明](指标策略合并说明.md)。旧版发布记录仅描述旧版，不代表当前可用规则。

## 启动

从本仓库 Release 下载 Windows ZIP，完整解压，双击 `一键启动.bat`。首次需要联网安装 Python、Node.js 等组件和依赖。浏览器打开 http://localhost:5173 。退出运行请用 `一键关闭.bat`。

本机数据位于 `backend/data`，不要删除。发布包不包含行情库、Telegram Token 或个人设置。私有仓库更新需先执行 `gh auth login`，再在看板检查更新。升级前备份数据，详见 [安装与更新说明](安装与更新说明.md)。

## 数据含义

异常候选不是指标买卖点；指标事件不是实际成交。每项规则只按自身条件触发，没有平仓规则时不虚构平仓。确认信号按已收盘 K 线更新，并非逐笔毫秒信号。首次历史预热只补任务要求的区间，不代表所有币种从上市起的全部历史。

可做度／活跃度是结构与行情评分，不是胜率。盘口缺失或不通过保留真实状态；回测不能凭 K 线还原未保存的历史盘口。兼容计算通过不代表通过交易规则或高胜率验证。

其他指标策略及其移植代码、Pine 源码、开发采集工具和相关旧研究结果已清理。活跃度、可做度依赖的基础行情与结构评分计算保留，它们不作为独立指标策略供选择。

## 运行边界

采集需要电脑醒着、后台运行和网络可用。不会绕过官方访问限制。限速按本进程共享预算处理；相同公网 IP 的其他软件仍可能造成限流，不能保证零封禁风险。参见 [币安 API 审计](BINANCE_API_AUDIT.md)。Telegram 内存待发送队列尚不保证崩溃恢复。

仅监听本机，不应直接暴露到公网。Telegram 私有审批和独立用户设置保留。第三方原始源码及改编部分的许可、署名要求见 [第三方声明](THIRD_PARTY_NOTICES.md)、[许可](LICENSE.md) 和源码内声明；私有仓库不取消这些义务。
